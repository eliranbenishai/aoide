## Question

What should Tramp’s v1 scalable UI **look and behave like** in concrete form: one-window app chrome (no OS frame), resize edges, drag-to-move, close/minimize, dense playlist-centric player — distinctive spiritual-successor feel, not a generic Material/Fluent shell?

Produce a cheap, reactable prototype (linked from this ticket) using the locked stack where practical, sufficient to lock visual direction for the spec.

**Design language:** Variant B — warm paper/ink surface (`#f2ebe0` / `#1a1410`), Syne wordmark, terracotta accent (`#c43c17`), hard 2px borders, ink primary buttons.
