# 12. Tramp is GPL-3.0-or-later

Date: 2026-08-14

## Status

Accepted

## Context

v1 bundles full libmpv/FFmpeg (the Windows pin is a GPL shinchiro build with `--enable-version3`). A proprietary Tramp would have required an LGPL rebuild of that stack. Open-sourcing was chosen instead ([ADR 0010](0010-open-source-website-download.md)).

## Decision

Tramp is licensed **GPL-3.0-or-later**. Proxima Magnifica keeps copyright. Contributions are inbound=outbound under the same license (no CLA unless that is decided later). Each published binary is paired with corresponding source via the public GitHub repo.

## Consequences

A `LICENSE` file and third-party notices (Flutter, fonts, mpv/FFmpeg, etc.) ship with source and installers. The name **Tramp**, the maker's plate, and tramp.music remain trademarks of the project, not grants under the GPL.
